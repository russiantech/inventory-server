# Production FastAPI Deployment — `/deploy` 🚀

Clean, DRY, Gunicorn-first deployment for cPanel shared hosting.

## What You Get

| Feature | Implementation |
|---------|---------------|
| **Process Manager** | Supervisor (auto-restart, boot persistence) |
| **App Server** | Gunicorn + `UvicornWorker` (production ASGI) |
| **Scaling** | Auto workers: `(2×CPU)+1`, capped at 4 |
| **Zero-downtime restarts** | Gunicorn SIGHUP graceful reload |
| **CI/CD** | `ci.sh` — git pull → test → migrate → reload |
| **Health Monitoring** | `monitor.sh` — HTTP + process checks (cron) |
| **Recovery** | `recovery.sh` — escalates to hard reset if needed |
| **Single Source of Truth** | `config.env` — one file drives everything |

## File Structure

```
/home/simpdinr/inventory-api.simplylovely.ng/
├── deploy/
│   ├── config.env          ← EDIT THIS
│   ├── _lib.sh             ← Shared helpers (sourced, never run)
│   ├── deploy.sh           ← One-time setup
│   ├── control.sh          ← Daily ops (start/stop/logs/health)
│   ├── ci.sh               ← CI/CD pipeline
│   ├── release.sh          ← Manual release trigger
│   ├── monitor.sh          ← Health monitor (cron)
│   ├── recovery.sh         ← Emergency recovery
│   └── gunicorn.conf.py    ← Generated by deploy.sh
│
├── main.py                 ← Your FastAPI app
├── requirements.txt
├── .env                    ← Secrets (chmod 600)
└── logs/
    ├── app.log
    ├── app.error.log
    ├── access.log
    └── error.log
```

## Quick Start

### 1. Configure

Edit `deploy/config.env`:

```bash
CPANEL_USER="salesne2"
DOMAIN="inventory-api.simplylovely.ng"
PYTHON_VERSION="3.13"
PORT=8001
WORKERS="auto"          # or 2, 3, 4
```

### 2. Deploy (one-time)

```bash
cd ~/inventory-api.simplylovely.ng
bash deploy/deploy.sh
```

### 3. Manage

```bash
bash deploy/control.sh status
bash deploy/control.sh logs
bash deploy/control.sh restart
bash deploy/control.sh health
```

## CI/CD

### Automatic (Git webhook or cron)

```bash
# In your repo server/webhook:
cd ~/inventory-api.simplylovely.ng && bash deploy/ci.sh
```

### Manual

```bash
bash deploy/release.sh
```

## Monitoring

Add to crontab:

```bash
*/5 * * * * bash /home/simpdinr/inventory-api.simplylovely.ng/deploy/monitor.sh
```
